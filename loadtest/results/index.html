Analisis Bottleneck Infrastruktur

Bahan evaluasi laporan praktikum Pertemuan 3
1. Titik Kegagalan Sistem:

Arsitektur tidak mengalami error 500 atau timeout koneksi hingga beban 1.000 VU (error rate 0,00%). Titik kegagalan terletak pada Service Level Agreement (SLA) response time, di mana p95 melebihi batas 1,5 detik saat beban melampaui 500 VU.

2. Bottleneck Skenario Baseline (1 Replika):

Satu proses worker Uvicorn mengalami saturasi CPU penuh (>130%). Permintaan antre dalam buffer koneksi sehingga latensi meningkat proporsional terhadap jumlah VU, membatasi throughput pada angka ~125 req/detik.

3. Efektivitas Auto Scaling:

Auto scaling berhasil menaikkan kapasitas pemrosesan hingga +47,1% (107.347 request) dan memangkas median latensi sebesar 73,6% (dari 2,65 detik menjadi 0,70 detik). Lonjakan p99 terjadi sesaat saat proses startup container baru menerima alokasi beban trafik dari Nginx load balancer.

4. Rekomendasi Optimasi Lanjutan:

Penerapan caching in-memory (Redis) untuk endpoint agregasi /api/dashboard, penambahan index komposit pada tabel PostgreSQL tracking_events(shipment_code, recorded_at), serta pemisahan node database master-replica.
