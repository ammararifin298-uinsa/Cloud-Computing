Prosedur DR Test

Jalankan di PowerShell pada folder proyek
  1. Catat waktu mulai, lalu matikan paksa database gudang utama Get-Date -Format "HH:mm:ss.fff" docker kill warehouse-db
  2. Simulasi kehilangan data (opsional) docker rm warehouse-db docker volume rm logistik-dr_pgdata
  3. Nyalakan ulang database dan tunggu hingga status healthy docker compose up -d db docker compose ps db
  4. Pulihkan dari file backup terbaru docker cp backups\NAMA_FILE.dump warehouse-db:/tmp/restore.dump docker exec warehouse-db pg_restore -U logistik -d logistik --clean --if-exists /tmp/restore.dump
  5. Verifikasi sistem siap menerima input tracking baru, lalu catat waktu selesai curl.exe http://localhost:8000/health Get-Date -Format "HH:mm:ss.fff"

RTO = waktu selesai (langkah 5) dikurangi waktu mulai (langkah 1). Data yang masuk setelah backup terakhir merupakan potensi kehilangan data (RPO, maksimal satu interval backup).
